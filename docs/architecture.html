System Architecture

Factory Inventory Management System

A full-stack demo for inventory tracking, order management, demand forecasting, and spending analytics across factory warehouses. Vue 3 single-page app talking to a FastAPI backend over a plain REST/JSON API — no database, all data held in memory.

Vue 3 + Vite · :3000 FastAPI · :8001 In-memory JSON · no DB SPA · client-side routing

Data Flow

One filtered request, end to end
1

User changes a filter

In the FilterBar, picking a Time Period / Warehouse / Category / Order Status updates the shared refs in useFilters (a singleton composable, so every view sees the same selection).

2

View requests data

The active view calls getCurrentFilters() and passes the object to api.js, which builds a query string and skips any filter whose value is 'all'.

3

HTTP request crosses to the backend

axios sends e.g. GET /api/orders?warehouse=Tokyo&month=Q4-2025 to http://localhost:8001. CORS is wide-open in dev so the cross-port call succeeds.

4

FastAPI filters in memory

The route reads the matching list from mock_data and runs apply_filters() + filter_by_month() — plain Python list comprehensions, case-insensitive, with 'all' meaning "no filter". Quarters expand via QUARTER_MAP.

5

Pydantic validates the response

Each endpoint declares a response_model, so results are coerced and validated against typed models before serialization to JSON.

6

Vue renders derived state

Raw rows land in ref()s; computed() properties derive totals, charts (custom SVG) and tables. useI18n localizes labels/currency (en→USD, ja→JPY) at display time.
